### B. Java & Spring Boot Backend Engineering
- **Core Java Foundation:** Multithreading, Concurrency, Collections framework (`HashMap`, `ArrayList`, `ConcurrentHashMap`), Exception Handling.
- **Spring Boot:** Dependency Injection, REST Controllers, Spring Data JPA/Hibernate, Security (JWT/OAuth2).
- **Relational Databases & SQL:** Schema design, indexing, transactions, ACID properties, query optimization.

### C. System Design & Distributed Systems Fundamentals

- Load balancing, horizontal vs. vertical scaling, stateless backends.
